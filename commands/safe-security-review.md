# Safe Security Review

Inspect the requested scope for practical risks including exposed secrets, unsafe permissions, authentication and authorisation gaps, input validation, webhook handling, prompt injection boundaries, data exposure, and dangerous third-party integrations.

Do not run scanners, install packages, access secrets, change configuration, apply fixes, or send findings anywhere. Report evidence-backed risks, ranked remediation options, and verification steps only.

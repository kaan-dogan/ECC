# Safe Plan

Inspect the repository only with read-only tools. Restate the objective, identify ambiguities, find relevant code patterns, and produce an implementation plan with affected files, validation steps, risks, and rollback notes.

Do not edit files, run mutating commands, create branches, install packages, call external services, or delegate work. End by asking for explicit approval before any implementation begins.

# Safe Evaluation Design

Define success, failure, regression scenarios, measurements, acceptance criteria, and rollback signals. For voice-agent work, include realistic conversation scenarios, escalation behaviour, accuracy, tone, latency, call outcome, and privacy-safe test data.

Treat criteria as a living draft, not a rigid contract: present them for correction before implementation. Do not create or run tests, touch production data, or make any changes.

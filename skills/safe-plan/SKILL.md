# Safe Plan

Use this when acting on assumptions would be costly. Inspect only with read-only tools, restate the goal and assumptions, identify affected areas, risks, dependencies, validation, and rollback, then present a phased plan.

Do not edit files, run mutating commands, install packages, create branches, call external systems, or delegate implementation. End by waiting for explicit approval.
